# 🌿 Harit Setu – The Green Bridge

**Backyard to Blockchain | Carbon Credits for Indian Farmers**

Harit Setu is a platform that connects small-scale Indian farmers with corporate carbon credit buyers, enabling rural communities to monetize their sustainable farming practices through satellite-verified (ISRO) carbon credit generation.

## 🚀 Live Demo

🌐 **[https://harit-setu-55e7a.web.app](https://harit-setu-55e7a.web.app)**

## 🏗️ Architecture

- **Frontend**: Vanilla HTML, CSS, JavaScript
- **Auth**: Firebase Authentication (Google + Email/Password)
- **Hosting**: Firebase Hosting
- **Verification**: ISRO Satellite (NDVI) + IoT Sensors

## 🌾 Features

### Farmer Dashboard
- Carbon credit earnings & revenue tracking
- ISRO satellite NDVI verification maps
- IoT sensor monitoring (CO₂, temperature, humidity, soil carbon)
- NFT-based carbon credit minting on Polygon

### Company/MNC Portal
- Carbon credit marketplace with filters
- Portfolio management & credit retirement
- ESG reports & Verra-compatible certificates
- API integration for automated offsetting
